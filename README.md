# Voice coaching MVP research

Research for a Vinh Giang AI communication coach built around “Find the power of your voice.” It helps people use Stage Academy skills in online content, everyday conversations, and work. The first feature analyzes the five vocal foundations in `videos/`: rate, volume, pitch and melody, tonality, and pauses. Video review of posture, movement, gestures, power sphere, and facial expression is included in the MVP research; the corresponding Vinh lessons still need to be added to the source material. Archetypes are deferred.

The current repository contains research and a feature-extraction probe, not a working coaching app. The local probe demonstrates measurable rate and level contrasts in course examples; contextual coaching quality remains to be evaluated.
